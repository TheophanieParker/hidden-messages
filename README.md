# Hidden Messages

**Python · Steganography · Digital Information**

## Overview

Hidden Messages is a Python programming experiment exploring steganography: the practice of concealing information inside another form of digital media.

The program hides a short text message inside a PNG image and retrieves it later without visibly altering the image.

The project investigates the relationship between visible information and concealed data, demonstrating how an image can carry information beyond what is immediately apparent.

## Artistic and Technical Context

Images are generally understood as visual objects. However, digital images are also structured collections of numerical values.

Hidden Messages explores this dual nature of digital media by using image data as a carrier for text.

The experiment connects computational processes with broader questions about visibility, communication, interpretation, and the information embedded within digital objects.

## How It Works

The program uses **least-significant-bit (LSB) steganography**.

Each pixel in a digital image contains numerical colour values. By changing the least significant bit of selected colour values, the program encodes text while making only minimal changes to the image's appearance.

The program can:

1. Generate a sample PNG image.
2. Convert a text message into binary data.
3. Embed that data within the image's colour values.
4. Save a new PNG containing the concealed message.
5. Read the modified image and recover the original message.

The program supports non-interlaced, 8-bit RGB PNG images.

## Requirements

- Python 3
- No additional libraries required

## How to Use

First, generate a sample image:

```bash
python hidden_messages.py sample
```

This creates `original.png`.

Next, hide a message:

```bash
python hidden_messages.py hide original.png secret.png "Some things remain unseen."
```

This creates `secret.png`, which contains the concealed text.

Finally, retrieve the message:

```bash
python hidden_messages.py reveal secret.png
```

Expected output:

```text
Hidden message: Some things remain unseen.
```

These commands are intended to be run in a terminal from the project folder.

## Limitations

This project demonstrates information concealment, not encryption. The hidden message is not cryptographically protected.

The program is designed for compatible PNG files and does not support every PNG colour format.
